# 基准测试性能

本页面列出了多种用于 Alpha 寻找的方法。每种方法每天都尝试为所有股票给出分数/预测（例如预测股票的未来超额收益）。模型的分数/预测将被用作挖掘出的 Alpha。投资于分数较高的股票预期能获得更高的收益。

Alpha 通过两种方式进行评估：
1. Alpha 与未来收益之间的相关性。
2. 基于 Alpha 构建投资组合，并评估最终总收益。
   - 指标说明请参考[这里](https://qlib.readthedocs.io/en/latest/component/report.html#id4)

以下结果是各基准模型在 Qlib 的 `Alpha360` 和 `Alpha158` 数据集上，分别使用中国 A 股 & 沪深300数据运行的结果。每个指标的值是基于 20 次不同随机种子运行计算得到的均值和标准差。

下面显示的数字展示了每个模型整个 `workflow` 的性能。我们将在不久的将来更新 `workflow` 和模型以获得更好的结果。

# 贡献

如果您想贡献新模型，可以按照以下步骤操作：
1. 为您的模型创建一个文件夹
2. 文件夹应包含以下内容（可以参考[此示例](https://github.com/microsoft/qlib/tree/main/examples/benchmarks/TCTS)）
    - `requirements.txt`：所需的依赖项

    - `workflow_config_<模型名称>_<数据集>.yaml`：`qrun` 可以读取的配置文件。鼓励您在所有数据集上运行您的模型。
3. 您可以将模型集成为 [此文件夹](https://github.com/microsoft/qlib/tree/main/qlib/contrib/model) 中的一个模块
4. 请在上述**基准测试表**中更新您的结果，例如 [Alpha360](#alpha360-数据集)、[Alpha158](#alpha158-数据集)（每个指标的值是基于 **20 次**不同随机种子运行计算得到的均值和标准差。您可以通过 Qlib 提供的自动化[脚本](https://github.com/microsoft/qlib/blob/main/examples/run_all_model.py)完成上述操作，并在 .md 文件中获取最终结果。如果计算资源不足，可以在 PR 中寻求帮助）。
5. 在[新闻列表](https://github.com/microsoft/qlib#newspaper-whats-new----sparkling_heart)和[模型列表](https://github.com/microsoft/qlib#quant-model-paper-zoo)中更新首页信息。

最后，您可以发送 PR 进行审查（[这是一个示例](https://github.com/microsoft/qlib/pull/1040)）。


# 常见问题

问：名为 `*.py` 和 `*_ts.py` 的模型有什么区别？

答：名为 `*_ts.py` 的模型是为 `TSDatasetH` 设计的（`TSDatasetH` 会自动从表格数据创建时间序列）。名为 `*.py` 的模型是为 `DatasetH` 设计的（`DatasetH` 通常用于表格数据。但如果列之间具有时间序列关系，用户仍然可以将时间序列模型应用于表格数据集）。
